# ORVANO E-COMMERCE STORE

Premium Watches & Baggy Pants Fashion Store

## Overview
ORVANO is a premium luxury-inspired eCommerce website selling watches and baggy pants with a black & gold design system, smooth animations, and a modern shopping experience.

## Tech Stack
- Next.js 15
- React 19
- TypeScript
- Tailwind CSS
- Framer Motion
- GSAP
- PostgreSQL
- Prisma
- Stripe
- Cloudinary
- Vercel
